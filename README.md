# Ali Print Pack Website Redesign

A modern, responsive, multi-page static website for Ali Print Pack (PVT.) Ltd.

## Technology

- HTML5 for semantic page structure
- CSS3 for the responsive visual system and animations
- Vanilla JavaScript for navigation and small interactions
- SVG for lightweight interface graphics

This stack is fast, easy to maintain and deployable to Netlify, Vercel, Cloudflare Pages, GitHub Pages or conventional cPanel hosting.

## Project structure

```text
ali-print-pack-website/
├── index.html
├── about/
├── services/
├── products/
├── brands/
├── certifications/
├── quality-innovation/
├── contact/
├── careers/
└── assets/
    ├── css/
    ├── js/
    ├── images/
    └── videos/
```

## Preview locally

Open `index.html` directly, or run a local server from this folder:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.
