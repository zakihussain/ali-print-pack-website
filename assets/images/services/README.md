# Service images

These nine service images were sourced from Ali Print Pack's existing public website and cleaned for the redesign by removing the old text-card treatment and converting them to optimized WebP files.

Source pattern:

`https://aliprintpack.com/wp-content/uploads/2023/09/Image-[1-9]A-1080x694.png`

Files correspond to:

1. Offset Printing
2. Digital Printing
3. Printed Fabric Label (PFL)
4. RFID
5. Screen Printing
6. Woven Labels
7. CTP
8. Foil Stamping
9. Thermal Printing
