# Image assets

Place approved website images here. Suggested folders for the next design stage:

- `hero/` — homepage hero photography or video poster
- `products/` — packaging and print product photography
- `facility/` — machinery, team and factory images
- `brands/` — approved client logos
- `certifications/` — certification marks
- `icons/` — any custom icons not built in CSS or SVG

Use descriptive lowercase filenames such as `offset-printing-machine.webp`.
